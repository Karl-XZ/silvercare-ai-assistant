# 银龄智护 V1 硬件问题优先级

原则：**先关闭 P0，再冻结原理图。**

## P0 — 原理图/主控方案生死问题

### P0-01 ESP32-S3-MINI-1U-N4R2 的 2 MB PSRAM

问题：2 MB PSRAM 是否能稳定支撑 OV5640 + Wi-Fi + INMP441 + Audio OUT + BMI270 并发。

关闭条件：目标固件全功能连续运行 30~60 分钟，无 OOM、明显掉帧、音频中断、Wi-Fi 异常或重启。

### P0-02 BK7258 多媒体 + 无线并发

问题：最终 SDK 路线下 Camera + Audio + Wi-Fi + BLE 是否能够稳定同时工作。

关闭条件：确定 SDK 分支并完成同等 30~60 分钟并发测试。

### P0-03 BK7258 准确采购料号

当前候选：`BK7258QN88616`，供应商页面标注 8 MB Flash + 16 MB PSRAM。

问题：Beken 官方产品页只公开 BK7258 系列能力和“Flash/PSRAM 最高 16 MB”，当前尚未从公开原厂资料核对该完整订货码的存储配置。

关闭条件：供应商/原厂确认准确料号、Flash、PSRAM、封装、温度等级、最小采购量和价格。

### P0-04 骨传导单元参数

必须拿到：

- 阻抗；
- 额定功率；
- 最大功率；
- 是否确实需要双声道。

没有这些数据不能冻结功放。

### P0-05 I²S Class-D 功放

目标：两套方案优先共用同一颗/同系列功放。

关闭条件：器件可采购，电压/功率与骨传导单元匹配，并完成实机播放验证。

### P0-06 Power Tree

需要冻结：

- 1S LiPo；
- 充电 / Power Path；
- SYS_3V3；
- Camera 2.8V；
- Camera 1.2V/1.5V；
- Audio Power；
- 峰值电流与关键去耦。

### P0-07 两套 Pin Matrix

必须分别完成：

- DVP；
- Camera SCCB；
- I²S RX；
- I²S TX；
- Sensor I²C；
- BMI270 INT；
- USB；
- 功放 EN / Camera 控制；
- 调试/启动相关；
- 至少约 5 个可用 GPIO 余量。

## P1 — 功能闭环与供应商问题

- BMI270 INT1 / Android / 跌倒算法；
- INMP441 实时音频流；
- 0809 LRA 供应商参数与最终安装位置；
- 4 Pin 磁吸接口机械件和 ESD；
- 3D 打印外壳中的 PCB、电池、Camera、骨传导和 LRA 空间布局。

## P2 — 后续优化

- 是否将消费者接口简化成 2 Pin 纯充电；
- 是否更换更小 MIC；
- 是否需要第二 LRA / 第二 MIC；
- 更高分辨率/更高帧率 Camera 模式。

## 当前阶段出口条件

当以下四项完成后，进入两套原理图冻结：

1. 两套 Pin Matrix 无冲突；
2. Power Tree 核心器件有可采购候选；
3. 骨传导功放可确定；
4. 两颗主控的关键资源风险有明确验证计划或实测结果。
