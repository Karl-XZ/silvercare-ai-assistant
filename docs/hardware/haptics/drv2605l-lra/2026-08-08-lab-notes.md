# 2026-08-08 DRV2605L + 0809 LRA 实验记录

## 实验结论

**结论：技术方案可行。**

已经通过实机验证：

- XIAO ESP32-S3 可以通过 I²C 识别 DRV2605L；
- I²C 地址为 `0x5A`；
- 使用 Adafruit DRV2605 Library 可初始化芯片；
- 设置 LRA 模式、Library 6、内部触发后，可以播放 ROM 内置触觉效果；
- Effect 47 已成功让 0809 X 轴 LRA 产生短暂振动。

最终触觉交互规则尚未确定，本次只完成技术路径验证。

## 1. 初始硬件判断

目标硬件组合：

```text
ESP32-S3 + DRV2605L + 0809 X轴 LRA
```

0809 X轴线性马达属于 LRA，不能直接由 ESP32 GPIO 驱动，需要专用触觉驱动器。DRV2605L 支持 LRA，因此方案匹配。

## 2. 接线过程

```text
DRV2605L VIN  -> ESP32-S3 3V3
DRV2605L GND  -> ESP32-S3 GND
DRV2605L SDA  -> GPIO5 / D4
DRV2605L SCL  -> GPIO6 / D5
DRV2605L OUT+ -> LRA 一根线
DRV2605L OUT- -> LRA 另一根线
```

`IN/TRIG` 在纯 I²C 内部触发测试中不是必需输入。

当前主控 IO 为 3.3 V，先用 3.3 V 给现有模块供电，可以避免部分模块 SDA/SCL 上拉到 5 V 的潜在风险。成品电源架构仍需结合模块实际原理图确认。

## 3. 第一次软件验证：I²C 扫描

```cpp
#include <Wire.h>

void setup() {
    Serial.begin(115200);
    Wire.begin(5, 6);
    for (uint8_t addr = 1; addr < 127; addr++) {
        Wire.beginTransmission(addr);
        if (Wire.endTransmission() == 0) {
            Serial.printf("Found I2C: 0x%02X\n", addr);
        }
    }
}
void loop() {}
```

### 上传过程中的问题

Arduino IDE 曾出现：

```text
Could not open COM13, the port is busy or doesn't exist.
PermissionError(13, '拒绝访问')
```

这是串口占用/端口状态问题，并非程序编译失败。后续重新处理串口后成功烧录。

### 扫描结果

```text
Build:Mar 27 2021
rst:0x1 (POWERON),boot:0x8 (SPI_FAST_FLASH_BOOT)
...
Found I2C: 0x5A
```

`0x5A` 与 DRV2605L 地址吻合，I²C 通路确认正常。

## 4. 第二次软件验证：安装驱动库

第一次编译出现：

```text
fatal error: Adafruit_DRV2605.h: No such file or directory
```

原因：Arduino IDE 尚未安装 `Adafruit DRV2605 Library`。

处理：Arduino IDE → Library Manager → 搜索 `Adafruit DRV2605` → 安装库和依赖。

## 5. 第三次验证：让马达实际振动

成功使用的核心配置：

```cpp
drv.useLRA();
drv.selectLibrary(6);
drv.setMode(DRV2605_MODE_INTTRIG);
drv.setWaveform(0, 47);
drv.setWaveform(1, 0);
drv.go();
```

串口输出：

```text
DRV2605L connected
Vibrate!
```

实际观察：**马达成功短暂振动/跳动一下。**

## 6. 为什么只“跳一下”

`drv.go()` 在 `setup()` 中，因此上电只触发一次 Effect 47，这是预期结果，并非异常。

## 7. 已确认的可扩展玩法

- Effect ID `1–123` ROM 效果巡检；
- Waveform Sequencer 多段节奏组合；
- RTP 实时强度；
- 心跳、呼吸、渐强、渐弱；
- 距离/风险映射；
- 未来双侧导航触觉编码。

注意：单个 DRV2605L 为单通道。未来左右两个 LRA 独立控制通常需要两颗驱动器，并处理相同 I²C 地址，例如通过 I²C MUX。
