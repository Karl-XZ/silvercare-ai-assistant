## 8. 语音与视频场景问题

### 8.1 现象

用户打开摄像头询问桌面有什么。应用约十秒后返回听不懂，但界面显示语音转文字已经完成。

### 8.2 判断

```text
录音 -> 本地 ASR -> 字幕文本         已完成
字幕 -> 意图判断 -> 当前画面分析      可能发生路由错误或等待
视觉结果 -> 中文答复 -> TTS          可能没有形成有效回复
```

正确本地路径必须取得当前摄像头帧、运行 DAMO-YOLO，再把检测框转成中文，不能让 Qwen 根据 ASR 文本猜画面。

### 8.3 已实现原则

- 当前画面/桌面询问直接调用 DAMO-YOLO。
- 没有可靠检测时，提示用户对准桌面、保持稳定、靠近或补光。
- ASR、视觉、文本、TTS 和 WebView 分别记录诊断事件。

### 8.4 既有真机回归


## 10. 找物模式故障与修复

### 10.1 修复前日志

真实请求“帮我找一下杯子”中：

- ASR 正确。
- `current_goal="杯子"`。
- DAMO-YOLO 原始结果包含 `cup`。
- 最终却返回 `target_detected=false`，并进入通用障碍逻辑。
- 行李箱测试出现同类问题。

### 10.2 根因

生产提示词：

```text
Current task: 找物目标：杯子
```

解释器只识别旧格式：

```text
正在寻找：杯子
Target: cup
用户正在找“杯子”
```

目标没有被取出，因此 `cup` 被按无目标导航解释。

### 10.3 修复

```java
String value = between(prompt, "Current task: 找物目标：", "\n");
```

随后继续兼容旧格式。新增测试用生产提示词和 `cup` 输出验证：

```text
target_detected=true
category=target
subject=杯子
```

### 10.4 2026-08-04 手机回归

```text

提示词=Current task: 找物目标：碗
```

## 11. 手动刷新耗时故障与修复

### 11.1 修复前

手动刷新日志显示 `force_refresh=false`。DAMO-YOLO 只需约 0.43～0.46 秒，但智能刷新调用 Qwen 比较前后场景需要约 13～16 秒。

### 11.2 根因

```text
refreshNavigationOnce
  -> tick({force:true})
  -> sendFrame(blob)                 force 丢失
  -> AndroidSilverCare.sendFrame
  -> SilverCareProcessor.processFrame
```

### 11.3 修复链路

```text
tick({force:true})
  -> sendFrame(blob, {force:true})
  -> AndroidSilverCare.sendFrameWithOptions(..., true)
  -> submitFrame(..., true)
  -> processor.processFrame(..., true)
  -> processNavigationFrame(..., true)
```

### 11.4 真机真实点击

```text
processor_navigation_frame_start force_refresh=true
native_vision_end elapsed_ms=395
mnn_vision_end elapsed_ms=400
processor_navigation_frame_end elapsed_ms=409
```

同一刷新周期没有 `smart_navigation_refresh_start`。结论：手动刷新降至 409 ms，不再等待 Qwen 比较。

## 18. 最终结论

银龄智护已经形成可运行的 Android 端侧 AI 链路：Vosk 完成离线语音识别，DAMO-YOLO 提供当前摄像头视觉事实，Qwen3/Qwen2.5 通过 MNN 承担文本理解，vivo V2509A 已确认 SME2 可用并采用 41 / 2 配置。

本轮修复了找物目标无法进入视觉解释器、手动刷新错误触发十几秒 Qwen 比较两个关键问题。最新版本已安装到手机，APK 哈希一致，手动刷新实测 409 ms，找物流水线和自动化测试通过。

必须继续保持边界：本地 Qwen 不猜测画面；DAMO-YOLO 只有固定类别；MNN TTS 当前未达到可懂度要求；个人 GitHub 新仓库推送当前没有完成证据。
